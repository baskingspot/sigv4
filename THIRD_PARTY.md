# Third-party

## The AWS signing test suite

`tests/aws-signing-test-suite/v4` is copied unmodified from
[awslabs/aws-c-auth](https://github.com/awslabs/aws-c-auth) at commit
`f556deacd6e6d9dbf540ff00a9bf383688076874` (v1.1.0), path
`tests/aws-signing-test-suite/v4`.

The suite is Copyright Amazon.com, Inc. or its affiliates, licensed under the
Apache License 2.0. `tests/aws-signing-test-suite/LICENSE` and `NOTICE` are
copied with it, and the Apache-2.0 terms apply to those files only.

`just test` runs every case, both the header signature and the presigned
variant, through the public module.

## The reference vectors

`tests/vectors/v4` is generated by `tests/vectors/generate.py` with botocore
1.43.79, the signer AWS ships in its Python SDK. The vectors cover the request
shapes the official suite does not have. The files are signature data, not
botocore code.
